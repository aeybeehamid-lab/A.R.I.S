A.R.I.S — Changelog

Running record of build progress, decisions, and fixes
July 21, 2026

Phase 1 core complete: gesture classification + debouncing

  • Added named gesture classification — fingers list mapped to Fist, Open Palm, Pointing, Peace Sign, Thumbs Up, with Unknown fallback
  • Added debouncing logic (lastGesture state tracking) so a held gesture fires once instead of every frame
  • Project restructured to VS Code (moved off PyCharm) for better cross-project consistency with the rest of the LME/ARIS stack
  • Rebuilt hand tracking pipeline from scratch, no tutorial dependency, with full understanding of each piece
July 21, 2026

Finger-state detection across all five fingers

  • Extended single-finger (index) up/down detection to all five fingers
  • Thumb handled via x-coordinate comparison (landmark 4 vs 2) due to its side-to-side orientation, rather than y-coordinate like the other four fingers
  • Output: fingers list of five 1/0 values representing extended/curled state per finger
July 21, 2026

Landmark coordinate extraction

  • Converted normalized mediapipe landmark coordinates (0–1 range) to real pixel coordinates using frame height/width
  • Stored all 21 landmarks per frame in an lmList list of [id, cx, cy] entries for downstream comparison logic
July 21, 2026

Fixed mediapipe / protobuf compatibility issue

  • Hit AttributeError: module 'mediapipe' has no attribute 'solutions' on initial install (mediapipe 0.10.35, latest at the time)
  • Root cause: protobuf version conflict — pip's resolver didn't select a fully compatible pairing
  • Fix: pinned mediapipe==0.10.14 and protobuf==4.25.3, confirmed working via direct import test
July 21, 2026

Environment setup: Python 3.11 + VS Code

  • Discovered mediapipe does not yet support Python 3.13 — no prebuilt wheels available
  • Confirmed Python 3.11 already installed locally; created project-local .venv using it
  • Migrated from PyCharm to VS Code per personal preference; configured interpreter, integrated terminal, and Python extension
  • Note: Code Runner extension uses a different default interpreter than the selected venv — running scripts via the integrated terminal (python hand_tracking.py) avoids this issue
July 21, 2026

Project initialized

  • Repository created and pushed to GitHub
  • Added .gitignore (excluding .venv/, __pycache__/, .vscode/) and requirements.txt for reproducible setup
  • Basic OpenCV webcam capture loop confirmed working as the foundation before adding mediapipe
